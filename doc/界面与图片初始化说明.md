# 登录界面、侧栏与图片初始化核对

日期：2026-11-12。

## 分析依据与修改边界

逐一读取并清点仓库内的文本代码和配置，核对既有[前后端逐文件分析](毕业论文/项目逐文件分析.md)的403项记录。401个工程文件的内容哈希与既有分析相同，两处变化为本次登录页和共用布局的样式。重点复核了登录提交与身份恢复、路由与岗位权限、所有图片显示入口、上传解码与UUID路径、独立绑定事务、共享引用回收、数据库种子及测试隔离方式。初始化脚本及回归用例为本轮新增。

三个岗位由同一个`AppLayout.vue`渲染侧栏，菜单由当前身份和权限代码决定；没有为各岗位复制布局。登录表单提交、密码清空、重复提交保护及安全重定向维持原实现。图片仍经过既有相对路径校验及`/media`入口读取，未新增第二套图片接口。
