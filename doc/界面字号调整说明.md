# 业务界面与顶部栏字号调整

日期：2026-11-12。

## 调整结果

| 内容 | 当前设置 |
| --- | --- |
| 业务正文、表格、表单标签、输入框 | 16px |
| 顶部面包屑（门店管理、当前页面名称） | 20px |
| 顶部账号名称、退出登录 | 16px |
| 顶部岗位名称、辅助说明、商品编码 | 14px |
| 页面主标题、区域标题 | 28px、20px |
| 工作台主要指标 | 36px |
| 详情与编辑弹窗标题 | 20px |
| 图表坐标轴、图例、饼图标签 | 14px；提示正文16px |
| 默认按钮、输入框、选择框 | 40px高；大号48px，小号36px |

三个岗位继续共用同一套布局和组件。顶部栏允许换行，筛选栏随宽度换行，表格保留自身横向滚动。编辑弹窗沿用限高和内部滚动，底部按钮保持可见；校验信息改为正常文档流，避免文字放大后遮挡下一项。

## 实现与维护

字号集中在 `frontend/src/styles/tokens.css` 的 `--font-size-*` 变量中，并统一映射至 Element Plus 字号。部分组件使用固定像素默认值，因此公共样式同时覆盖表单内容、详情字段、折叠面板、分页、日期面板和小号按钮，确保挂载在body下的弹窗也能使用相同字号。

`AppLayout.vue`负责顶部栏排版；各页面原有的小字号改为引用统一变量。`ReportChart.vue`从计算样式读取字号和字体，并提供ECharts主题；Canvas文字也随统一字号放大。销售图表增加标签留白并使用`containLabel`，不改变数据或点击下钻逻辑。

本轮共修改18个前端文件。后端、接口契约、身份权限规则、采购销售盘点逻辑、数据库结构及论文文件均未修改。
